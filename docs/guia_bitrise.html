Guía para dummies: compilar "Diagnóstico de Averías Fácil" con Bitrise

Bitrise compila la app en la nube. No necesitas instalar Flutter, Android Studio ni nada en tu ordenador: solo un navegador y tus cuentas de GitHub y Bitrise.

0Antes de empezar

Lectura: 2 minutos

Tres palabras que verás en Bitrise

PalabraQué significa
BuildUna compilación: Bitrise coge el código de GitHub y fabrica la app.
WorkflowLa receta de pasos que sigue. La nuestra se llama android_apk y ya está escrita en el archivo bitrise.yml del repositorio.
Artifact (artefacto)El resultado que sale al final: el archivo mx5diag.apk para instalar. No es algo que tengas que subir tú.
Stack / MachineEl ordenador virtual en la nube donde compila (por ejemplo "Mac Intel 14 GB" o "Ubuntu"). No es tu ordenador; no necesitas tener nada parecido.

1Darte de alta en Bitrise

Tiempo: 3 minutos · Solo la primera vez

  1. Ve a bitrise.io y pulsa Sign up (o Get started).
  2. Elige Sign up with GitHub y acepta los permisos que pida.
  3. Si pregunta por un plan, elige el gratuito (Hobby / Free). Si pregunta nombre de "workspace", pon el que quieras, por ejemplo enric.
Listo cuando…Ves el panel de Bitrise (Dashboard) con un botón para añadir apps.

2Añadir la app a Bitrise

Tiempo: 5 minutos · Solo la primera vez

  1. Pulsa Add new app (o + New project). Si te ofrece un asistente "Web UI" o "Classic", elige el asistente web normal.
  2. Privacidad: elige Private.
  3. Repositorio: elige GitHub → enricgilargelaget/mx5diag. Si no aparece, pulsa el enlace para dar acceso a Bitrise a tus repositorios de GitHub y selecciónalo.
  4. Acceso al repositorio (SSH): deja la opción automática (Add own SSH no hace falta) y pulsa Next.
  5. Rama (branch): escribe main.
  6. Bitrise analizará el proyecto. Cuando pregunte por la configuración:
    • Si ofrece "Use the bitrise.yml from repository" (o "Store in repository"), elige esa. Es lo ideal: ya trae nuestra receta.
    • Si solo ofrece su configuración automática de Flutter, acéptala; luego en el paso 3 te digo cómo usar la nuestra.
  7. Si pregunta por Stack o máquina, deja la que proponga (Mac o Ubuntu valen las dos para Android).
  8. Si pregunta por un webhook, pulsa Register webhook: así compilará solo cada vez que yo suba cambios a GitHub.
  9. Termina el asistente. Puede que lance una primera compilación automáticamente; no pasa nada.
¿Te pide subir un archivo, un "keystore" o un "artifact"?Sáltalo (Skip). Para probar en tu móvil no hace falta.

3Lanzar la compilación

Tiempo: 1 minuto + 5–15 minutos de espera

  1. En Bitrise abre la app mx5diag.
  2. Pulsa Start build (o Run workflow, arriba a la derecha).
  3. Rama: main. Workflow: android_apk.
  4. Pulsa Start build y espera. Verás los pasos ponerse en verde uno a uno:
    1Git clone
    2Instalar Flutter
    3Preparar plataformas y permisos
    4Pruebas
    5Compilar APK
    6Deploy
¿No aparece el workflow "android_apk"?Es que Bitrise usa su configuración en lugar de la nuestra. Ve a Workflows (o Configuration) → pestaña bitrise.yml → busca la opción "Store in app repository" / "Use repository bitrise.yml" y actívala. Si no la encuentras, mándame una captura de esa pantalla.

4Descargar e instalar el APK

Tiempo: 3 minutos

  1. Cuando la compilación salga en verde (Success), entra en ella y abre la pestaña Artifacts.
  2. Descarga mx5diag.apk. Lo más fácil: abre bitrise.io desde el propio móvil Android y descárgalo ahí directamente.
  3. Abre el archivo descargado. Android dirá que es de "origen desconocido": pulsa Ajustes → activa Permitir de esta fuente → vuelve atrás → Instalar.
  4. Si Google Play Protect avisa, pulsa Más detalles → Instalar de todas formas (es tu propia app, sin firmar para la tienda).
Listo cuando…Se abre la app Diagnóstico de Averías Fácil con el coche cromado sobre fondo azul y las 5 pestañas abajo. El botón Ver Azul simple cambia al estilo blueprint.

5Probar con el coche

Tiempo: 5 minutos

  1. Enchufa el ELM327 en el conector OBD-II (bajo el salpicadero, lado del conductor) y pon el contacto.
  2. No lo emparejes desde los Ajustes de Bluetooth del móvil.
  3. En la app: pestaña OBD → Buscar adaptador OBD (BLE) → acepta los permisos → toca el adaptador (suele llamarse OBDII).
  4. Prueba Leer códigos, Medir batería y Datos en vivo. Vuelve a la pestaña Plano: las piezas se colorean según lo leído.
Si la búsqueda no encuentra el adaptadorProbablemente tu ELM327 es de Bluetooth clásico, no BLE. Dímelo y adapto la app para Android con Bluetooth clásico.

?Si la compilación sale en rojo

  1. Entra en la compilación fallida y haz clic en el paso en rojo.
  2. Baja hasta el final del registro y copia las últimas 30–40 líneas (o haz una captura).
  3. Pégamelas en el chat. Yo corrijo el código y lo subo a GitHub.
  4. En Bitrise pulsa Rebuild (o lanza otra vez Start build). Si registraste el webhook, empezará sola.
Error típicoQué hacer
"Repository not found" o fallo en Git cloneBitrise no tiene acceso al repositorio: en la app → Settings → Repository, vuelve a conectar GitHub.
Falla en Pruebas o Compilar APKEs un error de código: pásame el registro.
"Out of build minutes"Se han gastado los minutos gratuitos del mes: espera al mes siguiente o mejora el plan.

+Cuando quieras cambios en la app

  1. Pídemelos en el chat (por ejemplo "añade tal pantalla").
  2. Yo modifico el código y lo subo a GitHub.
  3. Bitrise compila solo (o pulsas Start build) y descargas el nuevo APK, que se instala encima del anterior sin perder tu historial.
